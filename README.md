# car-block-coding

A block-based programming app for controlling an Arduino robot car using Blockly and Electron.

## Features
- Drag-and-drop block programming
- Arduino code generation
- Upload support for Arduino-compatible boards

## Development

```bash
npm install
npm start
```

## Project Structure
- `electron/` - Electron app shell and browser window
- `src/` - Blockly blocks, renderer, code generation, and uploader logic
